AutomationShield Serial Monitor 1.0.0
=====================================

FOR APPLE SILICON MACS (M1, M2, M3, M4 OR NEWER)

INSTALLATION
1. Drag SerialMonitor.app to the Applications folder.
2. Open SerialMonitor from Applications.

FIRST LAUNCH
This app is currently distributed without an Apple Developer ID signature.
If macOS blocks the first launch:

1. Try to open SerialMonitor once.
2. Open System Settings > Privacy & Security.
3. Scroll to Security and click Open Anyway.
4. Confirm by clicking Open.

After this confirmation, macOS will remember the exception.

USAGE
1. Connect the Arduino UNO R4 WiFi by USB.
2. Close the Serial Monitor in Arduino IDE if it is open.
3. Start SerialMonitor and select the /dev/cu.usbmodem... port.
4. Click Start before logging in to the Arduino through the website.

Website: https://mrsolutions.sk/automationshield/
